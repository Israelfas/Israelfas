## 👋 Sobre mí

Soy estudiante de Ingeniería en Software en la **ULEAM** (Manta, Ecuador 🇪🇨) y desarrollo software de punta a punta: desde el modelado de la base de datos y la API hasta la interfaz que usa el cliente.

Combino proyectos académicos con trabajo real para clientes, y me interesa que lo que construyo funcione bien, se entienda y se pueda mantener.

- 🧱 Me gusta diseñar bien el backend: modelos, módulos y colas de trabajo
- 🎨 Cuido que el frontend sea claro y cómodo de usar
- 🌱 Aprendiendo ahora: **TypeScript a fondo, Docker y arquitectura limpia**
- 🔧 Prefiero sacar una primera versión y mejorarla que esperar a que quede perfecta
